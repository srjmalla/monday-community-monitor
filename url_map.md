## How to add or update a keyword

1. Open `config.py`
2. Find the app's section in `KEYWORD_INDEX`
3. Add a new dict: `{"phrase": "exact phrase users type", "app": "App Name", "url": "https://..."}`
4. The phrase must be lowercase and match what users literally type into search
5. Run `python3 -c "from config import KEYWORD_INDEX; print(len(KEYWORD_INDEX), 'phrases')"` to verify it loaded
